# PixelForge 网页图片编辑器

PixelForge 是一个基于 React、TypeScript、Fabric.js 和 Zustand 的浏览器端图片编辑器。项目保留了 Photoshop 风格的深色界面，并提供图片、文字、图形、画笔、图层、滤镜、历史记录和导出等常用编辑能力。

所有编辑都在浏览器本地完成，项目当前不包含后端服务，也不会主动上传用户图片。

## 功能

- JPG、PNG、WebP 图片上传、拖拽导入和剪贴板粘贴
- 图片与对象的选择、移动、缩放、旋转、翻转和透明度调整
- 画布缩放、抓手拖动、自动适配视图
- 可撤销的画布裁剪
- 画笔与橡皮擦，支持大小、颜色和不透明度
- 可再次进入编辑状态的文字图层，以及字体、字号、排版和颜色设置
- 矩形、椭圆、直线、三角形工具
- 图层选择、排序、拖拽换序、隐藏、锁定、复制、重命名和删除
- 亮度、对比度、饱和度、曝光、色温、模糊及多种滤镜预设
- 最多 60 步撤销 / 重做历史
- PNG、JPG、WebP 导出，可设置透明背景、质量和输出倍率

## 环境要求

- Node.js 18 或更高版本
- npm 9 或更高版本
- 支持 Canvas 2D 的现代浏览器，推荐最新版 Chrome、Edge 或 Safari

## 本地运行

```bash
npm install
npm run dev
```

开发服务器默认地址为 `http://localhost:5173/`。局域网访问地址会由 Vite 在启动时一并输出。

## 检查与构建

```bash
# TypeScript 类型检查
npm run typecheck

# 生产构建，输出到 dist/
npm run build

# 本地预览生产构建
npm run preview
```

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 移动 / 选择、抓手、裁剪 | `V`、`H`、`C` |
| 画笔、橡皮擦、文字 | `B`、`E`、`T` |
| 矩形、椭圆、直线、三角形 | `R`、`O`、`L`、`Y` |
| 撤销 / 重做 | `Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z` |
| 打开图片 / 导出 | `Ctrl/⌘ + O`、`Ctrl/⌘ + S` |
| 全选 / 取消选择 | `Ctrl/⌘ + A`、`Ctrl/⌘ + D` |
| 复制选中图层 | `Ctrl/⌘ + J` |
| 删除选中图层 | `Delete` 或 `Backspace` |
| 适配画布 / 缩放 | `Ctrl/⌘ + 0`、`Ctrl/⌘ + +`、`Ctrl/⌘ + -` |
| 临时抓手 | 按住空格并拖动 |

在文字编辑或属性输入框中，上述全局快捷键会自动让位于浏览器原生输入行为。

## 项目结构

```text
src/
├── components/          # 编辑器界面、图层和属性面板
│   ├── sections/        # 不同对象类型的属性区块
│   └── ui/              # 通用输入与展示组件
├── hooks/               # 全局快捷键
├── lib/
│   ├── engine.ts        # Fabric 画布、对象、图层、历史和导出核心
│   ├── adjustments.ts   # 图片滤镜与参数映射
│   ├── defaults.ts      # 默认配置和通用常量
│   └── registry.ts      # 滤镜预设注册
├── store/               # Zustand 编辑器状态
├── types.ts             # 共享类型
└── main.tsx             # 应用入口
```

`EditorEngine` 是 Fabric 画布的唯一控制入口；Zustand 保存可供 React 界面订阅的文档、工具、图层、选区、调整参数和历史状态。React 组件不会直接重建或修改 Fabric 对象，避免重渲染造成画布内容丢失。

## 当前限制

- 当前没有 PSD、SVG、HEIC、RAW 导入，也没有 PSD 导出。
- 橡皮擦以可撤销的内部合成轨迹实现，不会在图层面板中为每一笔创建图层；它会擦除轨迹下方的可见内容，而不是直接改写原图像素。
- 历史记录仅保存在当前页面内，刷新或关闭页面后不会恢复。
- Fabric.js 6 的 npm 安全审计包含 SVG 序列化相关公告以及 Node 端可选依赖告警。当前产品未开放 SVG 导入/导出，且只在浏览器中运行；升级到 Fabric.js 7 需要单独进行兼容性迁移和完整回归，不建议直接使用 `npm audit fix --force`。

`dist/`、`outputs/`、Vite 临时时间戳文件和本地工具记录均不纳入 Git；它们可通过构建或测试重新生成。
